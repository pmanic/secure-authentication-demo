# Web Security Laboratory

Aplikacija poredi nezaštićenu i zaštićenu registraciju, prijavu i izmenu korisničkog profila. Prikazuje SQL Injection, XSS i CSRF ranjivosti i načine njihove zaštite, kao i čuvanje lozinki pomoću PBKDF2.

Tehnologije: Java 17, Spring Boot, JDBC, H2, Maven, HTML, CSS i JavaScript.
